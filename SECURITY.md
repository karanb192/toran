# Security

Toran is a static site. It has no accounts, no server and no stored visitor data. The parts worth checking are the door contribution flow (the issue form, `scripts/add-door.mjs` and the workflow that opens a pull request) and anything that puts visitor text on the page.

To report a vulnerability, email karan@karanbansal.in rather than opening a public issue. Please include steps to reproduce. You should get a reply within a few days.
